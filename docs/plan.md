# Plan

This document is the one plan of nimblescape Markdown and of the products
that build on it or stand beside it: the libraries, nimblescape Markdown
Notes, nimblescape Markdown Paper, nimblescape PlantUML, the course module
with its feedback program, the history and the reflection tool. It lists the
open steps in their order ([section 3](#3-open-steps)), the decisions that
wait for the owner ([section 4](#4-decisions-that-wait-for-the-owner)), the
requirements that are still proposals
([section 5](#5-requirements-that-are-still-proposals)), the actions that
only the owner can do ([section 6](#6-actions-of-the-owner)), and the steps
that are built ([section 7](#7-built-steps)). No other document of these
repositories holds a plan; they link here
([R-GEN-007](specification.md#r-gen-007)).

The requirements stay in the specification of each product, and this
document repeats none of them: a step names its requirements by their IDs.
A change that builds a step, adds a step, decides an open question or makes
a new one changes this document in the same pull request. The steps keep the
numbers that they have in their product, so that the code, the tests and the
documents that name a step, for example step 87 of Markdown Notes, still
find it in [section 7](#7-built-steps).

## 2. Order and rules

The products are built in this order: the editor of the libraries, Markdown
Notes, Markdown Paper, the course module, the history, the reflection tool.
A step of a later product may come first when an earlier step needs it.
These rules of all repositories ([R-GEN-007](specification.md#r-gen-007))
apply to every open step:

- Nothing is published before its release. The npm packages of the
  libraries are released together with Markdown Notes, their first user.
  Markdown Notes and Markdown Paper are released only when the owner asks.
  Until then, a repository installs a package of another repository from
  GitHub at a fixed commit.
- Every repository with TypeScript code uses exactly TypeScript 6.0.3, and
  its Dependabot proposes no other version of TypeScript.
- AI agents and CI call the commands of the products with npx, for example
  `npx -y @nimblescape/course check`, and never install them globally
  ([R-COURSE-005](course.md#r-course-005); decision 53 of
  [Markdown Paper](https://github.com/nimblescape/markdownpaper-vscode/blob/main/docs/requirements.md#decisions)).
- A pull request is merged or squash merged; nobody force pushes.
